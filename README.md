# JRS Core

**A free, open-source roleplay framework for RedM.**  
One framework, one visual style, ready to run.

---

This account hosts JRS Core, a complete RedM server pack built around one core, together with every
script of the pack as its own repository. All scripts share the same API, the same interface style and the same
database, so a new server works from the first start instead of after weeks of gluing resources together.

- **75 JRS resources** made to work together, each one in its own repository
- **One-click install** with a txAdmin recipe, database included
- **English and Arabic** in every interface
- **Free forever**, released under the GNU GPL v3

## Install

Use the txAdmin recipe (recommended): in txAdmin choose **Remote URL Template** and paste:

```
https://raw.githubusercontent.com/JRS-CORE/jrscore/main/recipe/jrscore.yaml
```

Or download the full pack from [JRS-CORE/jrscore](https://github.com/JRS-CORE/jrscore) and follow its README.
